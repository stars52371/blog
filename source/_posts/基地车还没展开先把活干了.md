人在外地，住在便宜小旅店，工作还没找到。

台机在拉箱里，没展开。就像是个没展开的基地车，在箱子里吃灰。那台机器的配置怎么说也比笔记本强得多，以前在上面折腾过黑苹果、Windows、Linux 各种系统，如今纯纯一台 Windows 游戏机，和朋友打打塔科夫、星际公民，都算够用。

但暂时没有打开的必要。旁边就有网吧，实在想打游戏也有的去。现在的处境是先找到工作，然后再正式租房，再把所有东西释放出来。

于是干活的事情就交给了这台笔记本。

## 笔记本配置

机械革命 无界14 PRO，双系统 Windows + EndeavourOS（Arch 系），干活全在 Arch 这边，桌面环境是 Hyprland + Wayland。

完整配置如下：

这台机器性能还行，日常使用完全够用。

## 工作流的迁移

说实话整套工作流搬过来，比预想的顺利不少。做好了踩坑的准备，结果坑确实有，但不多。

### 编辑器

还是 VS Code，没变。跨平台，配置同步一下就好，没什么可说的。

### 写博客

Hexo 那套命令完全没有变化，`hexo new`、`hexo g`、`hexo d`，该怎么用怎么用。这是静态博客的好处——只要 node 能跑，一切都不成问题。

图床用的是在线服务，打开浏览器登录就行。图床客户端之前用的就是开源软件，Linux 这边直接安装，没有任何障碍。

### 图像处理：从 PS 到 GIMP

以前在 Windows 上做 banner 用 PhotoShop，Linux 这边换成了 GIMP。

GIMP 现在的界面易用性确实令人刮目相看，比 2.0 时代进步太多了，操作逻辑也清晰了不少。不过转念一想，GTK 最初就是为了 GIMP 而开发的（GIMP Toolkit），如果这么多年过去还没有像样的进步，那才说不过去。

总之能用，而且用起来挺顺手。

### 终端与字体

这一块 Linux 从来就比 Windows 做得更好。字体渲染、终端配色，没什么需要适应的，以前就是 Linux 更胜一筹，现在依然是。

### Dotfiles

直接 clone 了我很喜欢的一个作者的仓库：

{% link https://github.com/zakack/end4-hyprland zakack/end4-hyprland %}

整套配置走的是 Google 的 MD3 设计风格，审美在线。clone 下来跑完脚本直接用，省去了从头配置的功夫。

## 也不是没踩坑

Hyprland 新版本将配置文件改成了 Lua 格式，语法和以前的 conf 文件不一样了。

我之前习惯直接在配置文件里写 `exec = fcitx5 -d --replace` 或者 `env = QT_IM_MODULE,fcitx` 这种东西，结果保存重载之后，屏幕上方弹出一条红条——没注意到已经换成了lua文件。

好在不是什么大问题，查了一下正确的写法，改了之后就正常了。

## 迁移之后

这次迁移用「顺利」来形容并不为过。EndeavourOS 提供了图形安装界面，安装过程比我想象中顺手得多——可以直接从现成的桌面环境里选择，传统的命令行手动安装也保留了，无论是新手还是老用户都能照顾到。

但要说心情的话，其实很平淡。不是那种「全搞定了」的兴奋，也不是「怎么这么多坑」的暴躁。更多的是一种……无可奈何。我也没招，凑合过呗。

台机在箱子里，人在小旅店，工作还在找。但日子还是得过。

也不知道什么时候能把基地车展开。先这样吧。
